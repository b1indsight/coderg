## 分阶段诊断

随后在独立源码副本中加入临时计时，并在同一插桩二进制中保留旧版收集实现，
通过环境变量切换。四种模式（新旧 release、新旧插桩路径）共用旧版生成的
临时索引，随机交错预热 5 轮、计时 31 轮，种子 20260909。输出 87 行一致。
插桩没有写入生产源码。

| 阶段 | 中位数 ms |
|---|---:|
| 旧版整个快照收集 | 14.941 |
| 新版路径枚举及批次汇总 | 10.992 |
| 新版按父目录分组 | 1.344 |
| 新版并行批量元数据处理 | 7.680 |
| 新版最终排序 | 1.483 |
| 新版整个快照收集 | 21.552 |

各阶段中位数独立计算，不要求精确相加。新旧 release 完整进程分别为
30.317 / 23.296 ms，新旧插桩进程分别为 30.571 / 23.809 ms，复现约 7 ms 回退。

每次收集选中 6,929 个文件，分布在 895 个父目录（平均约 7.7 个文件/目录）。
批量阶段额外打开这 895 个目录，调用 `getattrlistbulk` 1,790 次，其中包含
每目录的 EOF 查询，读取 7,764 条目录项；逐文件回退次数为零。

当前接法保留了原目录枚举，再追加目录分组和第二次目录访问。虽然减少了
逐文件查询，但没有把目录遍历与元数据获取合为一遍，因此新增阶段抵消了收益。
批量处理计时还包含目录打开、返回值解析、HashMap 操作及路径构造，不能全部
归于系统调用。原始报告中的 `open_worker_ms` 和 `syscall_worker_ms` 是多个
并行工作线程的耗时累计，不是关键路径墙钟时间，不应与上表直接相加。
