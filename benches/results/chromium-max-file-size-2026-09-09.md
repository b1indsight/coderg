# Chromium 搜索 MAX_FILE_SIZE — 2026-09-09

> 文档状态（2026-09-10）：历史 JSON manifest 版本的搜索测量，源码快照没有 Git 历史，不用作真实 commit 更新实验。二进制格式后的结果见[后续实测](chromium-binary-manifest-2026-09-09.md)。

coderg 默认搜索中位数为 **2.055 秒**，rg 默认搜索为 **7.923 秒**，约快 **3.86 倍**。coderg `--no-refresh` 为 **264 毫秒**，约快 **30.01 倍**。所有模式都返回相同的 **98 个文件、114 行匹配**，计时前后均已校验。

## 语料与方法

- Chromium 官方主仓库快照，提交 `398630472335c10b9ca610a4d1b7888a040f702a`，下载地址：`https://chromium.googlesource.com/chromium/src/+archive/398630472335c10b9ca610a4d1b7888a040f702a.tar.gz`。
- 只含主仓库快照，未同步 DEPS 外部依赖，无 Git 元数据。源码位于 `/private/tmp/coderg-chromium-3986304/src`，索引位于其同级 `index` 目录。
- 索引覆盖 461,882 个文本文件、3,040,624,852 字节（2.83 GiB）；索引 2,098,987,148 字节（1.95 GiB）。
- 当前工作区 `cargo build --release --offline` 构建；macOS arm64，10 个逻辑 CPU。二进制 SHA-256、rg 版本及精确命令见原始数据。
- 固定字符串搜索，输出包含路径、行号和完整匹配行，计时输出重定向到 `/dev/null`，包含进程启动时间。
- 预热 3 轮，随机交替计时 15 轮，种子 20260909。未清空系统文件缓存；无并发编译或其他由本次任务启动的 benchmark。
- coderg 默认包含目录扫描式索引新鲜度检查；`--no-refresh` 跳过该检查。无 Git 元数据这一条件可能影响默认搜索性能，不应直接外推到完整 Git checkout。
- rg 默认及 `--hidden -g '!.git'` 都测量；后者用于对齐 coderg 包含隐藏文件的行为。本查询两者匹配结果一致。禁用 rg 配置，使用 `LC_ALL=C`。

## 限定命中文件的补充测试

将 rg 的输入直接限定到已知的 98 个命中文件，共 112,927,089 字节（107.70 MiB），预热 5 轮、随机交替测量 51 轮。正则 `MAX_FILE_SIZE` 搜索中位数 **7.319 ms**（6.432–9.359 ms），固定字符串模式中位数 **7.089 ms**（6.514–8.650 ms）。包含进程启动、文件读取、行号及完整匹配输出，stdout 重定向到 `/dev/null`；结果与全仓搜索相同。

这是已知命中文件上的微基准，不包含发现这 98 个文件的成本，不能替代全仓搜索结果。后续 [coderg 分阶段剖析](chromium-search-profile-2026-09-09.md)测得实际候选为 102 个文件，读取与匹配约 4.95 ms；[原始微基准数据与完整命令](data/chromium-max-file-size-2026-09-09/matched-files-results.json)保留了全部样本。

## 首次建索引

首次建索引单次实测 **65.24 秒**，不计入上述搜索耗时。使用默认 256 MiB 工作缓冲预算，产生 58 个临时构建段，累计临时写入 21,873,965,676 字节，峰值临时数据 14,676,352,952 字节。缓冲预算不是进程内存上限；本次未测峰值 RSS。下载约 1.38 GiB 压缩包另耗时约 3 分 30 秒，解压也不计入搜索和建索引时间。
