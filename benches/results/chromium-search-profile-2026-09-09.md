# Chromium MAX_FILE_SIZE 搜索性能剖析

> 文档状态（2026-09-10）：JSON manifest 基线的历史剖析，只用于定位瓶颈。二进制 manifest 已在 main 基线落地，见[后续实测](chromium-binary-manifest-2026-09-09.md)；本分支没有再次实现该格式优化。

瓶颈是每次启动时读取、反序列化完整 JSON manifest。`--no-refresh` 下索引加载约 **231 ms**，占进程耗时约 **90%**；真正的倒排筛选约 **0.54 ms**，读取并匹配候选文件约 **4.95 ms**。

## 方法

沿用 [Chromium 基准](chromium-max-file-size-2026-09-09.md) 的源码快照、已有索引和固定字符串查询。在 `/private/tmp/coderg-chromium-perf-20260909` 建立源码副本，仅向副本插入 `Instant` 分阶段计时，构建优化开启、带调试符号的 `profiling` 二进制。未修改产品源码或原 release 二进制。

默认搜索和 `--no-refresh` 随机交替，预热 2 轮、测量 15 轮，每次启动独立进程。捕获 stdout/stderr，每次核对输出均与原始 114 行结果相同。各阶段记录墙钟耗时，非累计 CPU 时间；各项独立取中位数，不能精确相加。进程总时间还包括启动、CLI 解析及未列出的退出清理。插桩和输出捕获会带来少量测量扰动。

macOS 使用 `/usr/bin/sample`，5 秒、1 ms 采样间隔。采样单独进行，通过临时入口循环 120 次搜索维持进程存活，每次仍完整加载并释放索引；该循环样本仅用于定位热点，不代替独立进程计时。

## 跳过 refresh

| 阶段 | 中位数 ms |
|---|---:|
| 完整进程 | 256.43 |
| 索引加载合计 | 231.05 |
| ↳ 读取 manifest | 34.09 |
| ↳ JSON 反序列化 | 197.17 |
| ↳ segment 映射及校验 | 0.075 |
| 编译正则 | 0.030 |
| 生成查询策略 | 0.004 |
| 倒排查询、候选筛选 | 0.538 |
| 读取候选文件、匹配并构造输出 | 4.950 |
| 结果排序及输出 | 0.081 |
| 释放索引及结果 | 11.83 |

实际候选 **102 个文件**，最终命中 **98 个文件、114 行**。插桩后的总时间与原 release 测得的 263.96 ms 接近。

manifest 约 **208 MiB**，包含整个仓库的 `source_state` 和 `documents`，其中路径和部分元数据重复保存。`index::load` 无论是否开启 refresh，都会通过 `fs::read` 和 `serde_json::from_slice` 完整加载 manifest；因此即使只需匹配 102 个候选，也先承担了全仓库元数据的解析、分配与后续释放成本。

调用栈采样主线程 3965 个样本中，3637 个落在 `index::load` 分支，约 91.7%。可见热点包括 UTF-8 校验、JSON 字符串扫描、键解析、整数解析和分配/释放，与分阶段计时一致。其他 Rayon 工作线程的大量条件变量等待样本不应被解读成 CPU 运算热点。

|---|---:|
| 完整进程 | 2014.32 |
| 索引加载 | 215.32 |
| refresh 合计 | 1749.15 |
| ↳ 遍历、忽略规则及文件元数据收集 | 1657.14 |
| ↳ 合并各线程记录 | 1.72 |
| ↳ 路径排序 | 72.49 |

refresh 快照实际包含 **506,050 个文件**，多于 461,882 个可搜索文本文件：刷新需要跟踪遍历范围内的普通文件状态，包含当前不可搜索的文件。遍历和元数据收集占 refresh 约 **94.7%**，其余包括排序、快照比较及临时记录释放。此快照没有发生变化，未重建或写回索引。源码中的 Git 同 HEAD 路径同样执行全量文件快照检查。

## 优化方向

优先处理查询启动时全量 JSON 反序列化：将搜索所需文档表与刷新状态分离，考虑可 mmap、按需访问的二进制布局，避免每次分配全仓库路径。常驻进程缓存已解析索引也是一种方案。倒排筛选和实际匹配占比很小，当前不应作为第一优化目标。

若要压低默认搜索的约 1.75 秒 refresh，还需要单独解决全目录状态扫描，例如维护文件事件驱动的变化记录，同时设计丢事件后的全量校验机制。这与优化 manifest 加载是两个独立问题。以上为优化建议，本次未实施。
